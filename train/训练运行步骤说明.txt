========================================================================
  YOLO 训练运行步骤说明（train 部分）
========================================================================
说明：本文档面向不熟悉训练流程的读者，解释「train」目录里的训练作业
如何运行、依赖什么、产物在哪、遇到问题怎么办。所有内容均已在本机
实际验证过（训练已成功跑通一次）。

------------------------------------------------------------------------
一、这个训练是干什么的
------------------------------------------------------------------------
train 目录用 ultralytics 库训练 YOLO 目标检测模型（负责"识别图像里
有什么物体、在哪"）。训练出来的权重文件 best.pt 会被同项目下的
chat 聊天室自动加载，实现"发一张图，自动识别出里面的人和物体"。

涉及文件：
    train\train.py     训练主脚本
    train\predict.py   对验证集图片批量检测并保存结果图
    train\webcam.py    打开摄像头做实时检测（按 q 退出）

------------------------------------------------------------------------
二、环境要求（本机已全部满足，无需再装）
------------------------------------------------------------------------
1. Python 3.14 及以上
2. ultralytics 库（训练框架）      -- 已安装 8.4.175
3. PyTorch（深度学习框架）         -- 已安装 2.14.1，CUDA 可用
4. NVIDIA 显卡（可选，但有更好）   -- 你的 RTX 5070 Ti 正在用，显存约 12GB

验证命令（任选一个终端窗口执行）：
    py -c "import torch; print(torch.__version__, torch.cuda.is_available())"
    py -c "import ultralytics; print(ultralytics.__version__)"

如果显示 cuda True，说明 GPU 训练可用（速度远快于 CPU）。

------------------------------------------------------------------------
三、怎么跑训练
------------------------------------------------------------------------
在项目目录下打开终端（cmd 或 PowerShell），执行：

    cd C:\Users\YI_YOU\Desktop\yolo-chat\train
    python train.py

train.py 当前内容：

    from ultralytics import YOLO
    model = YOLO("yolo11n.pt")
    results = model.train(data="coco8.yaml", epochs=3, imgsz=640,
                          name="train", exist_ok=True)

逐行解释：
    yolo11n.pt      官方预训练权重。第一次运行会自动下载（约 5MB），
                    之后用本地缓存。用它做迁移学习，比从零训练快很多。
    data=coco8.yaml ultralytics 内置的小数据集（8 张图片），用于快速
                    验证流程能不能跑通。
    epochs=3        训练 3 轮。只是验证用，精度有限；真正要用的模型
                    需要换成自己的数据集，epochs 加大到几十上百。
    imgsz=640       输入图片尺寸。
    name="train"    固定产物目录名，保证下游脚本路径永不失配。
    exist_ok=True   允许覆盖旧训练结果，重复训练不用手动删目录。

预计耗时：8 张图 3 轮，GPU 下约 1 分钟；自动完成下载、训练、验证三个
阶段。看到 "3 epochs completed ... best.pt" 即表示成功。

------------------------------------------------------------------------
四、训练产物在哪里（重要）
------------------------------------------------------------------------
产物目录：train\runs\detect\train\

关键文件：
    weights\best.pt   训练出的最优权重（约 5.5MB），后续检测都用它
    weights\last.pt   最后一轮的权重
    results.csv       每轮损失、mAP 等指标
    results.png       训练曲线图
    labels.jpg        数据集标注可视化

下游脚本（predict.py / webcam.py / chat 聊天室自动检测）都固定从
    runs\detect\train\weights\best.pt
读取权重，所以只要这个文件在，它们就不需要任何配置。

五、运行训练时可能遇到的两个常见问题（均已解决）
------------------------------------------------------------------------
问题 1：下载 yolo11n.pt 或数据集失败（SSL / 连接超时）
原因：ultralytics 默认从 GitHub 等海外地址下载资源，国内网络不稳。
现象：日志里出现
      "Download failure ... SSLError ... EOF occurred ..."
解决：分两类 -
      1) 预训练权重 yolo11n.pt：多试几次即可（本次首次失败后重试成功）。
      2) 数据集（如 coco8）：需要手动用国内镜像下载并解压到数据集目录。
         coco8 的下载地址：
         https://gh-proxy.com/https://github.com/ultralytics/assets/
             releases/download/v0.0.0/coco8.zip
         解压目标目录（ultralytics 默认数据集目录）：
         C:\Users\YI_YOU\Desktop\train\datasets\
         解压后目录结构应为：
         datasets\coco8\images\train\  (4 张图)
         datasets\coco8\images\val\    (4 张图)
         datasets\coco8\labels\...     (标注)
         注：本机已把 coco8 解压好，结过上述问题的第二步无需再做。

问题 2：训练结果找不到 / 下游脚本报缺 best.pt
原因：ultralytics 默认会在目录名后自动加编号（train、train-2、train-3…），
      首次训练产物在 train\，第二次会生成 train-2\。
      而旧版 predict.py / webcam.py / chat 聊天室写死找 train-2\，两者
      不一致会导致"训练完成但下游找不到权重"。
解决：已把 train.py 固定为 name="train" + exist_ok=True（永远覆盖写
      回 train\ 这一个目录），并把三个下游脚本统一改为读
      runs\detect\train\weights\best.pt。现在无论训练多少次，路径都
      不会变。

七、以后想训练"自己"的数据集怎么办
------------------------------------------------------------------------
1. 准备图片与标注（标注格式推荐 YOLO 格式：每张图一个同名 txt，
   每行 = 类别 中心x 中心y 宽 高，类别从 0 开始编号）。
2. 目录结构参考：
       datasets\mydata\
           images\train\  images\val\
           labels\train\  labels\val\
3. 写一个数据集配置 yaml（参考 ultralytics 的 coco8.yaml），内容：
       path: <数据集绝对路径>
       train: images/train
       val: images/val
       names: {0: person, 1: car, ...}   # 按你的类别写
4. 改 train.py 一行后运行：
       model.train(data="你的.yaml", epochs=100, imgsz=640,
                   name="train", exist_ok=True)
   注意：如果数据集在本地，训练不联网，不会再有下载问题。

------------------------------------------------------------------------
八、常见疑问速答
------------------------------------------------------------------------
Q：训练没跑完，电脑能关吗？
A：不能，中断后需要重跑。训练很快（1 分钟左右），等它跑完再关。

Q：训练结果能提交到 git 吗？
A：不会也不建议。datasets/、runs/、*.pt 都在 .gitignore 里，属于
   可再生的下载/训练产物，体积大且没必要入库。

Q：换电脑或换目录后还能用吗？
A：能。所有脚本都用相对路径推算，不写死盘符；只要保持 chat/ 与
   train/ 同级（或 train 在 chat 内），重新跑一次训练即可。
