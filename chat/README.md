# chat0721

## 简介

一个简单的多人聊天室，完全使用 JS 完成前后端，通信选择了 WebSocket 协议，历史消息用 SQLite 持久化。

在基础聊天功能之上，接入了自己训练的 YOLO 模型：**在聊天里发送一张图片，系统会自动做目标检测，并把画好检测框的图片和识别结果发回聊天室。**

## 启动方式

双击 `start_ai.bat`，它会启动 Dify（可选）、后端和前端，并自动打开网页。
也可以手动 `node server.js` + `py -m http.server 8080`。

详细的环境要求和排错说明见 [运行说明.md](运行说明.md)，
架构设计和实现取舍见 [设计说明.md](设计说明.md)。

## 已实现功能

- 输入昵称与房间名后加入房间聊天，可同时加入多个房间并快速切换
- 消息实时广播、历史消息恢复、未读提示、断线自动重连
- 发送图片（点按钮选择 / 拖拽进窗口 / Ctrl+V 粘贴三种方式）
- 图片上传进度显示，断网时自动排队，恢复连接后补发
- **图片发送后自动调用 YOLO 检测**，返回标注图和「类别 + 置信度」列表
- 文本消息自动调用 Dify 生成 AI 回复

## 图片检测怎么用

1. 加入任意房间（所有房间都支持，不需要特殊配置）
2. 点输入框左边的 🖼 按钮选图，或直接把图片拖进聊天区，或按 Ctrl+V 粘贴
3. 回车发送
4. 图片会立刻出现，先显示上传进度，然后「正在检测…」
5. 几秒内 YOLO 会发出一条消息，包含画好框的图片和检测结果

> 需要 `py -m pip install ultralytics`。没有装的话聊天和发图仍然正常，
> 只是图片下方会显示「检测失败」，左侧栏会提示 YOLO 不可用。

## 项目文件说明

| 文件 | 作用 |
| --- | --- |
| `server.js` | 后端主程序：WebSocket 聊天、图片上传、静态图片、调用 YOLO |
| `detector.js` | Node 侧的检测桥接：找 Python、启动常驻进程、请求排队、崩溃重启 |
| `yolo_worker.py` | Python 常驻检测进程，模型只加载一次，按 JSON 行协议收发 |
| `detect.py` | 命令行版检测脚本，用于手动测试单张图片 |
| `index.html` | 前端页面与全部前端逻辑 |
| `style.css` | 样式，包含图片气泡和检测标签的样式 |
| `uploads/` | 运行时生成：`original/` 存原图，`annotated/` 存画好框的图 |
